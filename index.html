🚀 Quick Start Guide

1. Save Changes: Type in the Local Workstation. Click git add . then git commit to save to history.
2. Sync with Cloud: Use git push to send your code to the Remote, or git pull to get updates from teammates.
3. Branching: Click git branch to create a new experiment. Use the dropdown to switch between them.
4. Merge Conflicts: If git pull causes a conflict, edit the text to remove the <<<< markers, click Mark as Resolved, and then git commit.
